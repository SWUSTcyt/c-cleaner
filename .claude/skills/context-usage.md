# 上下文使用率检查 Skill

当用户询问上下文使用情况、token 用量、上下文剩余空间时，执行以下操作。

## 检查方式

1. 统计当前对话中所有消息的字符数
2. 按 1 中文字符 ≈ 2 token、1 英文单词 ≈ 1.3 token 估算 token 数
3. 参考常见模型上下文窗口大小，计算使用率

## 常见上下文窗口

| 模型 | 窗口大小 |
|---|---|
| Claude 4.x | 200K tokens |
| Claude 3.5 Sonnet | 200K tokens |
| Claude 3 Haiku | 200K tokens |

## 输出格式

```
上下文使用情况:
  已用 token:  ~XX,XXX (估算)
  上下文窗口:  200,000 tokens
  使用率:      XX.X%
  剩余空间:    ~XXX,XXX tokens

  [████████░░░░░░░░░░░░] 40.5%
```

## 注意事项
- 这是粗略估算，实际 token 数取决于分词器
- 当使用率超过 80% 时提醒用户考虑压缩或新开对话
- 对话早期的消息可能已被自动压缩/摘要
